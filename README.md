# herofashion — Process Tracker MVP

Simple process tracker for Herofashion: backend (Express + SQLite + JWT auth) and frontend (React + Vite). This commit scaffolds a minimal working MVP that includes:

- User accounts (register/login) with JWT
- Orders with dueDate and priority
- Stages (OrderMaster, Fabric, Cutting, Sewing, Packing/Ironing)
- Stage updates/history
- Basic React frontend with login and dashboard

Run backend: see backend/README or root README
